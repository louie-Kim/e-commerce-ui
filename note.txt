*const searchParams = useSearchParams(); url 감시
  ↓

  ↓
handleChange(slug) 실행
  ↓
new URLSearchParams(searchParams) → 기존 쿼리 복사
  ↓

  ↓
pathname + "?" + params.toString()

router.push(완성된 URL)

--------------------------------------------------------

배열에서 [] → 인덱스(숫자)로 값 꺼냄
const arr = ["a", "b"];
arr[0]; // "a"

대괄호 표기법(bracket notation)

객체에서 [] → 키(문자열 또는 변수)로 값 꺼냄
const obj = { red: "빨강", blue: "파랑" };
obj["red"]; // "빨강"

CSS 속성을 작성
